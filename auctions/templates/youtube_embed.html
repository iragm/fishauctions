But a stylesheet is cached and this markup is not: nginx serves /static/ with no Cache-Control, so a returning visitor can hold yesterday's auction_site.css against today's page, and a player that gets its height *only* from CSS renders as a full-width 150px sliver when that happens. So the JS also measures and passes real pixels, which ship with the HTML and cannot go stale. With the stylesheet loaded the CSS wins and nothing here is visible; without it these numbers are the whole layout.
