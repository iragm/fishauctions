{% comment %}The half of the cache that used to be invisible. A remembered wrong species is worse than a remembered "no": it is served ahead of the token search, to every club, and it ends up on a printed label and in a breeder award.{% endcomment %} These answers are served straight back without looking anything up, for every club, and they are written by the lot forms as well as by the language model. What stops one seller's wrong pick from being the site's answer for good is the last two columns: a lot saved with the answer left alone counts once, a lot it was cleared from or changed on counts against it, and one rejection in ten retires the row by itself. “Look it up again” throws the answer away without recording a rejection, so the matcher may well arrive at the same one.

{% comment %}Flagged by Species.save(), the same way an AuctionTOS gets flagged: same scientific name at the same rank, or the same designated common name. Merging is a superuser's call because it is not reversible and because it decides which name the whole site keeps.{% endcomment %} Two rows for one species happen when somebody adds a species the list already had under a name they didn’t search for. Two species genuinely sharing a common name is not a duplicate — say so and the pair stops being flagged.
