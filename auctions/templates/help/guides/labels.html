A label on each bag says which lot it is, so nobody has to look it up.

In person

Labels go on before the auction, so the auctioneer can call the lot.

Online

Labels go on after bidding ends, and say who won the lot.

You can scan the QR code on labels to open the lot's page.{% if help.site.labels_scanned is not None %} {{ help.site.labels_scanned }}% of lot labels from all in-person auctions are scanned, so I guess most people haven't yet figured out just how cool the phone app's scanning feature is.{% endif %}

In person: before you come

  1. Add all your lots first, so they fit on as few sheets as possible.
  2. On the auction's page, click {% page "print_my_labels" "Print Labels" %}. You get a PDF, one label per lot.
  3. Tape each label to its bag with clear packing tape.
{% aitip %}Added another lot? Ask "print my unprinted labels" and you can print only what you need to.{% endaitip %}

A label got wet or went missing? Open the lot and click {% page "single_lot_label" "Print label" %}.

{% aitip %}Ask "print the label for lot 12" and it opens the page, ready to print.{% endaitip %}

Online: after bidding ends

Only lots that sold need a label. You'll get an email when it's time.

{% tip %}"You don't have permission" when you print? You're signed in with a different account from the one your lots are under, often on a second device. Sign out and back in.{% endtip %}

Printing everybody's labels

If you run the auction, you can print anybody's:

One person{% ui "Print labels" %} next to their name on the {% page "auction_tos_list" "Users" %} tab. {% page "print_labels_by_bidder_number" "That page" %} prints all their labels; there's a {% page "print_unprinted_labels_by_bidder_number" "version for just the unprinted ones" %}. Quickest at the desk, as each seller arrives.
A few, or everyone{% page "auction_printing" "Print labels" %} under {% ui "More" %}. Tick the people and click print. You get {% page "auction_printing_pdf" "one PDF" %}.

The site remembers which labels have been printed, by anyone. Leave {% ui "Only print labels that haven't been printed yet" %} ticked and nothing prints twice.

One PDF holds up to 100 labels on a thermal printer, or 500 on sheets. More than that? Print again with "only unprinted" ticked for the next batch.

{% tip %}Printing hundreds of labels? The PDF can take up to 30 seconds to make, so you may want to print them in smaller batches.{% endtip %} {% mike %}Mike printed all 400 labels on the morning of the auction. Then three sellers added lots, so he printed all 400 again.{% endmike %} {% tip %}Get sellers to print their own. It saves you paper and an hour at the desk.{% endtip %}

Sheets, thermal printers and the phone app

What you print on is your own setting, on {% page "printing" "Label printing" %}. One admin can use a thermal printer and another a laser printer on the same night.

SettingGood for
Plain paperAny printer. Cut them out and tape them on. Fine for a few lots.
Large (Avery 18262)Sheet labels on a laser printer. Inkjet ink runs when the bag gets wet.
Small (Avery 5160)Cheap and easy to find, but hard to read. Not recommended.
Thermal 3"x2"The one to buy if you're buying a printer: fast, no ink, and it takes water. Any thermal printer that takes 3"x2" labels works.
Thermal 1⅛" x 3½" (Dymo 30252)Dymo LabelWriters.
CustomYour own page and label sizes. Test a few first: problems show up on the fifth label, not the first.
  • A half-used sheet? Set {% ui "Empty labels" %} to the number already gone. Set it back to 0 for a fresh sheet.
  • A Bluetooth thermal printer prints straight from the phone app, no computer. Pick it on Label printing in the app, and every print button sends labels to it.
  • Trying a setting? Reprint labels from an old auction you sold in.

When labels come out wrong

On the wrong part of the sheetSome sheets have different margins top and bottom. Turn the sheet around.
An edge cut offTry Fit to page instead of Actual size in the print dialog, or the other way round.
Labels creep, skip, or come out page-sizedSet the printer to the label size, not Letter or A4, and recalibrate.
Faint lines across thermal labelsClean the print head.
Tiny, or the wrong sizeCheck {% page "printing" "Label printing" %} matches the paper, on the account you're signed in with.
