A breeder award program gives members points for fish they bred themselves, and a leaderboard to show off. Here, points come from lots sold in your club's auctions: a member ticks "I bred this", the lot sells, and the points are theirs. Plants (HAP) and live food cultures (CAP) can have programs of their own.

For members

  1. Add your lot to one of your club's auctions as usual.
  2. Pick the species from the list. Points depend on what it is, and a lot with no species may not earn any.
  3. Tick {% ui "I bred this" %}.
  4. When it sells, you get the points. Your club may check each one first.

The club page has a leaderboard for each program, this year's or all time, and your own points under {% page "club_detail_tab" "My points" %}. The {% page "selling" "Selling" %} page, searched for "bap", lists every lot you've had points for.

Points go to the club member who sold the lot, matched by your account or your email. Selling under a different email from the one your club has? Your points go nowhere until the club fixes it.

Turning it on

  1. Tick {% ui "Enable breeder award program" %} in the club's {% page "club_edit" "General" %} settings.
  2. Give your BAP chair the {% ui "Award points" %} permission. They don't need anything else.
  3. Set the rules on {% page "club_bap_settings" "BAP settings" %}, under Setup.
  4. Coming from a spreadsheet? Bring your old points across: see below.

Lots from before you turned it on count too, back to your club's first auction here. Don't be surprised to see points for lots members sold years ago.

The rules

Every rule is on {% page "club_bap_settings" "BAP settings" %}. Start with the defaults and change one when somebody finds a way round it.

{% ui "Auto add points" %}On: points are given the moment a lot sells. Off: every lot waits for your chair to approve it.
{% ui "Points per lot" %}A flat rate for every lot. Blank uses each category's own points instead. 0 gives nothing, unless an override below says otherwise.
{% ui "Points for custom checkbox" %}Bonus points when the auction's custom checkbox is ticked on a lot. Call the checkbox "CARES species" and give it 5.
{% ui "Min quantity" %}A lot needs at least this many fish. Stops one fry in a bag earning points. Plants, snails and live food are exempt.
{% ui "Days between same name lots" %}How long before the same member earns again for a lot with the same name. 0 means every time.
{% ui "Days between same species lots" %}The same, by species, so "Yellow labs" and "Labidochromis caeruleus" count as one fish. Strains count separately: blue and red cherry shrimp both earn.
{% ui "Only active members can participate" %}Members whose membership has lapsed earn nothing until they renew.
{% ui "Only donation lots" %}For clubs whose program is "breed it and donate it to the auction".
{% ui "Only sold lots" %}Off, a lot earns points even if nobody buys it. With {% ui "Auto add points" %} on, those points come a day after the auction ends.
{% ui "No minimum bids" %}A lot with its own minimum bid earns nothing. Stops a member listing at $50 to collect points without selling.
{% ui "Separate Horticultural Award Program (HAP)" %}Plants earn HAP points, with their own leaderboard, instead of BAP.
{% ui "Separate Live Food Culture Award Program (CAP)" %}Live food cultures, snails and other inverts earn CAP points. Without it, live food earns nothing.

Worth more, worth less

Below the rules are two kinds of override:

  • Per category: Killifish 15, Livebearers 5. Add Uncategorized at 0, so a lot nobody picked a species for earns nothing.
  • Per genus: Tropheus 20, even though the rest of the cichlids are 10. Only works on lots where the seller picked the species.

A lot takes the genus points if there are any, then its category's, then {% ui "Points per lot" %}, then the category's own default.

{% tip %}Change the rules at the start of the year, and tell members at a meeting. A rule that changes in September feels like somebody's being targeted.{% endtip %}

Approving points

{% page "club_bap_lots" "BAP" %}, in the club's menu, lists every lot from your club's auctions that a member sold. Filter it by {% ui "Pending" %}, {% ui "Approved" %}, {% ui "Rejected" %} or {% ui "Non-BAP (no checkbox)" %}.

  • Approve: check the points in the box, change them if you like, and click the tick.
  • Reject: the cross.
  • Wrong category? Click the category under the lot's name and pick the right one. That's also how a plant moves to HAP.
  • Changed your mind? {% ui "Undo" %} puts it back to pending.

The {% ui "Reason" %} column says why a lot didn't get points by itself:

{% ui "Didn't breed this fish" %}"I bred this" wasn't ticked. If they did breed it, approve it anyway.
{% ui "Not a club member" %}The seller isn't on your member list under that account or email. Add them, or fix their email, and approve.
{% ui "Not an active club member" %}Their membership had lapsed.
{% ui "Not long enough since last submission" %}The days-between rules.
{% ui "Quantity below club minimum" %}{% ui "Min quantity" %}.
{% ui "Category not eligible (BAP points = 0)" %}Equipment, or a category you've set to 0.
{% ui "Species not eligible for breeder points" %}A species the site's list says can't earn them.
{% ui "Lot has a minimum bid set" %}, {% ui "Lot is not a donation" %}, {% ui "Not sold" %}The rules of the same names.

Points that didn't come from a lot

{% page "club_bap" "View awarded points" %} lists every award. {% ui "Add points" %} gives a member points by hand: a spawning report, a talk, a fish they bred and gave away at a meeting.

Bringing in old points

{% ui "Import CSV" %}, on the same page, takes a spreadsheet with an Email column, which has to match a member, and any of BAP, HAP, CAP, Date and Notes. You see what will be added before anything is. {% page "club_bap_import" "Importing" %} only ever adds: it never changes or deletes an award, so check the preview before you import the same file twice.

Showing it off

  • The club page's leaderboards switch between {% ui "Year to date only" %} and all time. The year's totals start again on January 1st.
  • The {% page "bap_embed" "leaderboard snippet" %} puts your top ten on your own website. See Events and your website.
  • Discord roles can follow points: "Master breeder" at 500. See Discord.
  • An API key with {% ui "Can use BAP points and lots" %} lets your own BAP spreadsheet or program read and add points.
