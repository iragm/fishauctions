Your club page has a calendar. Your auctions go on it by themselves, and you add meetings, swaps and talks. From there it feeds your members' own calendars, a Google calendar, your Discord and your club's website, so you only ever type an event once.

Events

{% page "club_event_add" "Add event" %}, on your club page, needs a {% ui "Title" %} and when it {% ui "Starts" %}. {% ui "Ends" %}, {% ui "Location" %} and {% ui "Description" %} are optional; with no end, it's two hours long.

  • Auctions add themselves once they're promoted, along with the pickup time of an online auction with one pickup location. They're marked {% ui "Automatic" %}, and they move when the auction does.
  • Want the auction's event to say more? Click {% ui "Edit" %} on it and change its title and description: "Monthly meeting and auction, doors at 6:30". It still follows the auction's date.
  • Called off? Edit it and tick {% ui "This event is cancelled" %}. It stays on the calendar, crossed out, so nobody drives to a locked hall.

Members' own calendars

Above the events on your club page, {% ui "Google Calendar" %} and {% ui "Apple Calendar or Outlook" %} add your club's calendar to a member's phone. It's a subscription, not a copy: a meeting you move here moves in their calendar too.

{% tip %}Tell members about those two buttons once, at a meeting. It's the difference between "I didn't know it was this week" and a full room.{% endtip %} {% aitip %}Ask "add the March meeting to the club's events, 7pm at the library".{% endaitip %}

Google Calendar

If your club already keeps a Google calendar, or wants one, {% page "club_google_calendar_config" "Google Calendar" %} under Setup keeps it and this site in step, both ways, every 15 minutes.

  1. Click {% page "google_calendar_connect" "Connect Google Calendar" %} and sign in with the club's Google account, not your own.
  2. Google's permission screen has a box for calendars that's easy to miss. Tick it.
  3. The site makes a new calendar, "Your Club events", and can only see that one. Events you add to it in Google show up on your club page.
  4. To let members subscribe to it in Google, open that calendar's settings in Google and tick {% ui "Make available to public" %}. The page says when it's public.

The same page has two switches:

{% ui "Add auctions to the calendar" %}On unless you turn it off. Untick it if your auctions are already on your calendar some other way.
{% ui "Create Discord events for calendar events" %}Meetings and swaps get a Discord event too. Auctions have their own switch on the Discord page, so they never show up twice.

{% page "google_calendar_sync_now" "Sync now" %} doesn't wait for the 15 minutes. {% page "google_calendar_disconnect" "Disconnect" %} stops the syncing and leaves the calendar in your Google account. Without Google, your club page still has a {% page "club_events_ical" "calendar feed" %} that any calendar app can read.

{% mike %}Mike connected Google Calendar with his own Gmail. Then he stepped down, deleted his account, and the club's calendar went with it. Use the club's Google account.{% endmike %}

Your club's website

{% page "club_website_integration" "Website integration" %}, under Setup, has snippets to paste into your own site: WordPress (in a Custom HTML block), Wix, Squarespace or anything else that takes HTML. They update themselves, use your site's fonts and colours, and never show anything about your members.

{% page "club_events_embed" "Upcoming events" %}Your calendar. Pick how many to show.
{% page "club_past_events_embed" "Past events" %}What you've been doing lately. The one that tells a visitor your club is alive.
{% page "club_auction_embed" "Current auction" %}The auction you've made current, or the next promoted one. It clears itself a day after the auction ends.
{% page "club_announcements_embed" "Latest announcement" %}The last announcement you sent with {% ui "Website" %} ticked. One line at the top of your home page.
{% page "bap_embed" "Breeder Award leaderboard" %}Your top ten, names and points only. Only with the breeder award program on.
Calendar linksNot a snippet: the subscribe link and the calendar feed, for a button or menu your site already has.
{% tip %}Put the current auction snippet on your home page once and never touch it again. Between auctions it says there's nothing on.{% endtip %} {% aitip %}Ask "what can I put on our website?" and it hands you the code to paste.{% endaitip %}

API keys

For anything the snippets don't do, there's an API. {% page "club_api_keys" "API keys" %}, under Setup, lists your club's keys. {% page "club_api_key_create" "Create new key" %} makes one, with only the permissions you tick, and shows its instructions.

A sign-up form on your site adds members{% ui "Can add club members" %}
Your own renewal form, or your old membership system, renews people{% ui "Can renew memberships" %}
A page on your site lists your auction's lots{% ui "Read auction info" %} and {% ui "Read public lot info" %}
Your breeder award spreadsheet or program reads and adds points{% ui "Can use BAP points and lots" %}

Keep a key to one job, and give each one a name that says where it's used, "WordPress sign-up form". When the job goes away, {% ui "Revoke" %} the key.

  • {% ui "Read private lot info" %} adds buyers' and sellers' names. Never use a key with it on a public page.
  • Your form calls the email field "your-email"? Open the key and add it under {% ui "Field mappings" %}, so the form doesn't have to change.
{% tip %}You don't have to write the code yourself. Paste the key's instructions into an AI assistant and ask it to write the form.{% endtip %}
