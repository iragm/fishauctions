Signing in

{% ui "Sign in with Google" %} or {% ui "Sign in with Apple" %} is quickest: one click, no password. Otherwise click {% ui "Create account" %} and use your email.

If you don't sign up with Google or Apple, we'll send you an email to confirm. In the interest of keeping the help helpful, I'm not going to tell you that you need to click the link in your email to confirm it or to check your spam folder if you don't see it. You're reading the help, so you're already in the 1% of most tech savvy users.

Your name, address and phone

{% page "contact_info" "Contact info" %} holds your real name, phone and mailing address.

  • {% ui "Your name" %} goes on your invoices. Only the people running auctions you join see it.
  • {% ui "Your address" %} is where clubs mail your check when you sell. Keep it up to date.
  • The map pin is how the site knows what's near you.
  • Change it once and it changes in every club you're in, and in any recent auction.

Your {% ui "username" %} is public: it's on your lots, bids and chat messages, for anyone to see. {% page "change_username" "Change username" %} changes it. Untick {% ui "Username visible" %} in your {% page "preferences" "Preferences" %} to bid anonymously. The people running an auction still see who you are.

{% if help.signed_in %}{% helptip %}{% ui "Username visible" %} is {% if help.account.username_visible %}on{% else %}off{% endif %} for you.{% endhelptip %}{% endif %}

To use a different email, go to {% ui "Change email" %}. Only you can change it. It doesn't need to match your card account: any card can pay any invoice.

{% aitip %}Ask "my new address is 12 Mill Lane". It updates every auction and club that has the old one.{% endaitip %}

Notifications

{% page "notification_preferences" "Notifications" %} is when the site may contact you:

  • {% ui "Auctions near you" %}, online and in person: one message per auction, only if you haven't been on the site for a few days. Set how far "near" is.
  • Questions on your lots, and replies to yours.
  • A reminder when you look at an auction but don't join.
  • {% ui "Push notifications when lots sell" %}: at an in-person auction, a notification when a lot you're watching comes up. Works in the phone app or a web browser: turn them on and test them.
  • With the phone app: notifications instead of emails, and a running total of what you've bought.
{% if help.signed_in %}{% helptip %}You have lot notifications turned {% if help.account.lot_alerts %}on{% else %}off{% endif %}{% if help.account.app %}, and {% if help.account.push_instead_of_email %}get notifications instead of emails{% else %}get emails, not notifications{% endif %}{% endif %}.{% endhelptip %}{% endif %}

Every email has a one-click unsubscribe link at the bottom. {% page "messages" "Chat notification setup" %} picks which lots' questions you hear about.

Emails from auctions

When you join an auction, add lots, or your invoice is ready, the site emails you on behalf of the people running it.

{% tip %}Reply to any of those emails and your reply goes to them: the auction organizer. It's the quickest way to ask about drop-off, pickup, or a lot with a problem.{% endtip %}
