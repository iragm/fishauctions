Where replies go

Emails about your club's auctions and memberships come from the club's own addresses on this site. They never change, however often your officers do. {% page "club_email_settings" "Emails" %}, under {% page "club_setup" "Setup" %}, lists them, and says who each one reaches.

{% if help.club and help.is_club_admin and help.club.auction_sender_email %}{% helptip %}{{ help.club.name }}'s addresses are {{ help.club.auction_sender_email }} and {{ help.club.contact_sender_email }}.{% endhelptip %}{% endif %}

Pick your auction chair for {% ui "Auction replies" %} and your membership chair for {% ui "Contact replies" %}. Leave {% ui "Donation replies" %} blank: vendors' replies are filed on the donation page either way. See Donations from vendors.

If the page asks for a {% ui "Membership email address" %} instead, replies to membership emails go to that address.

Membership emails

On {% page "club_email_settings" "Emails" %}, below the boxes, each email is shown as a member will see it. Click into the preview and type your own opening and closing: "Our next meeting is the second Tuesday, and the pizza's on us." Then (probably) tick all four boxes:

  • {% ui "Send welcome letter to new club members" %}
  • {% ui "Send membership renewal confirmation" %}
  • {% ui "Send expiration reminder 30 days before membership expires" %}
  • {% ui "Send expiration reminder the day before membership expires" %}
{% if help.club and help.is_club_admin and help.membership_emails_off %}{% helptip "envelope" %}Still off for {{ help.club.name }}: {{ help.membership_emails_off|join:", " }}.{% endhelptip %}{% endif %}

{% ui "Also include information about the next event" %} adds whatever's next on your {% page "club_google_calendar_config" "club calendar" %}.

{% if help.club and help.is_club_admin and not help.club.google_calendar_connected %}{% helptip "calendar-x" %}{{ help.club.name }} hasn't connected a calendar yet.{% endhelptip %}{% endif %}
  • People you import from a spreadsheet don't get the welcome letter. Adding one person by hand, untick {% ui "Send welcome letter" %} on them to hold it until they first pay dues.
  • Somebody added without one, say from an auction with {% rule "send_club_welcome_letter" %} off, gets it when they first pay dues.
  • Every email has a link at the bottom where members pick all emails, essential ones only, or none. What they picked shows as their {% ui "Contact status" %}.
{% tip %}A new member says the welcome email never came? Nine times out of ten it's in their spam folder.{% endtip %}

Announcements

{% page "club_announcements" "Announcements" %}, in the club's menu, sends one message everywhere at once. It needs the {% ui "Send announcements" %} permission, because it goes straight to members' phones and inboxes with nobody checking it first.

  1. Type it in {% ui "Announcement" %}. The whole thing goes out everywhere; there's no "read more".
  2. Tick where it goes: {% ui "Discord" %}, {% ui "Push notifications" %} (members with the phone app), {% ui "Mailchimp" %} or {% ui "Brevo" %}, and {% ui "Website" %}: the top of your club page and the announcement snippet on your own site. A box you can't tick says what to connect first.
  3. {% ui "Send later" %} to schedule it, or leave it blank to send now.
  4. {% ui "Send announcement" %}.

Sent the wrong thing? You have 30 seconds to {% ui "Retract" %} it before anything leaves. After that, Retract still deletes the Discord post and takes it off your website; emails and phone notifications already sent stay sent. A scheduled one has a {% ui "Cancel" %} button until it goes.

The list of recent announcements counts how each one did: Discord, phones reached, emails opened, and times shown on your website.

{% tip %}Keep announcements to a sentence or two. People read them on a locked phone screen.{% endtip %} {% mike %}Mike announced the swap meet, then announced the change of venue, then announced the correction to the change of venue. Members with the app got three buzzes in ten minutes and turned notifications off. Read it twice, send it once.{% endmike %} {% aitip %}Ask "send the club an announcement that Thursday's meeting moved to the 14th".{% endaitip %}

Mailchimp and Brevo

Connect one and your member list keeps a mailing list up to date by itself: new members added, details changed, people who asked for no email dropped. You write and send newsletters in Mailchimp or Brevo, as you do now.

Mailchimp{% page "club_mailchimp_config" "Mailchimp settings" %}, then {% page "mailchimp_connect" "Connect" %} and sign in to Mailchimp. {% page "mailchimp_select_audience" "Choose an audience" %}, or have one made for you.
Brevo{% page "club_brevo_config" "Brevo settings" %}. In Brevo, make an API key (it starts xkeysib-), paste it, and {% page "brevo_connect" "Connect" %}. Then {% page "brevo_select_list" "choose a list" %}. The free plan is decent, with no logo on your emails.
  • Every member with an email is on it, and each change goes across as it's saved, and again every night.
  • It only goes one way. Edit people here, not there. The one thing that comes back is an unsubscribe.
  • {% ui "No non-essential emails" %} counts as unsubscribed; {% ui "Do not contact" %} takes them off.

Tags, for sending to some members

Each member is tagged, so you can write to just the right people. In Mailchimp they're tags; in Brevo they're in the MEMBER_TAGS field.

expiring-soon, expiredRuns out within 30 days, or already has. Your renewal campaign.
new-member, long-term-memberJoined in the last six months, or five or more years ago.
nearby, medium-distance, long-distanceUnder 10 miles from the club, 10 to 30, or further.
power-seller, power-buyerSold, or bought, over $1,000 in lots.
probably-inactiveNo club activity in six months.
admin, auction-checkin, discord-connectedHelps run the club; has checked in at an auction; is on your Discord.
CategoriesUp to five categories each member buys and sells most. Mail the cichlid people about the cichlid speaker.

Emails can also fill in each member's own details: their membership number, expiration date, barcode, and a link to renew. The settings page lists every field.

{% tip %}Want the welcome and reminder emails to look like your newsletter? Turn them off on the Emails page and build them in Mailchimp or Brevo, triggered by the new-member and expiring-soon tags.{% endtip %}

Discord

{% page "club_discord_config" "Discord" %}, under Setup, links your club to its Discord server. Members get roles to match their membership, and your announcements and auctions post there.

  1. {% ui "Connect Discord server" %} adds the site's bot to your server. Type /connect in the server and paste the code from the Discord page.
  2. In Discord's role settings, drag the bot's role above every role it should hand out. It can't give out a role above its own.
  3. {% page "club_discord_send_join_message" "Post the join button" %}. Members click it and type their email; the ones already on your member list are matched, and anybody else is added.
  4. {% page "club_discord_fetch_roles" "Fetch roles from Discord" %}, then click a role to decide who gets it: {% ui "Paid membership role" %}, {% ui "Unpaid / expired membership role" %}, or a {% ui "BAP points threshold" %} or {% ui "HAP points threshold" %}. Roles change by themselves as people renew, lapse or earn points.
  5. Type /announcements_here in the channel for announcements, and /auctions_here in the one for auction news.

Tick {% ui "Automatically create a Discord scheduled event for each promoted auction" %} and each auction shows up in Discord's events, too. Meetings and other calendar events can do the same; see Events and your website.

{% tip %}Emails people enter in Discord aren't verified in any way, so don't put anything private behind the paid-member role.{% endtip %}
