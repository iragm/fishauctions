Connect Claude to this site

Claude can use this site the same way you do — look up a lot, check who hasn't paid, add lots to your auction, check people in. It acts as you: every auction and club still checks your own permissions, so it can never do anything you couldn't do yourself.

You currently have {{ tool_count }} things it can do{% if opted_in %}, {{ read_tool_count }} of which only look things up and never change anything{% endif %}.

What it can do

  • Ask it things: “how many lots are in my auction?”, “who hasn't paid yet?”, “when does lot submission close?”
  • Have it do things: add lots, check people in, record a sale, mark an invoice paid, add points.
  • Anything that would take a page with a form on it — creating an auction, deleting things, anything involving money changing hands — it will give you a link to instead of doing.
  • It gets a shorter list if you don't run an auction or a club, because most of the list is only useful to somebody who does.

Claude, Claude Desktop and the mobile app

Nothing to copy but the address — you sign in instead.

  1. In Claude, open Settings → Connectors and choose Add custom connector.
  2. Paste the address above.
  3. Claude sends you here to sign in and asks what you're allowing. Say yes.
  4. That's it — ask Claude about your auction.
Claude Code

One command, then the same sign-in in your browser.

claude mcp add --transport http auctions {{ mcp_url }}

Then run /mcp inside Claude Code to sign in.

Using a key

Send it as a bearer token on every request:

curl -X POST {{ mcp_url }} \
  -H "Authorization: Bearer ak_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Connecting to less than all of it

The whole list of {{ tool_count }} tools is sent to your assistant every time it connects, and it costs it something to read. If you only want part of it, add ?tools= to the address:

  • {{ mcp_url }}?tools=club — members, points, events, announcements
  • {{ mcp_url }}?tools=auction — lots, bidders, check-in, invoices
  • {{ mcp_url }}?tools=read — only the tools that look things up
  • {{ mcp_url }}?tools=club,read — combine them with commas

The handful that orient it — what you're working on, where a page is, undo — are always included.

Good to know

  • A connection can change at most 300 things an hour. That's far more than a busy check-in table needs, and it's the ceiling on how far something can go wrong before you notice.
  • Whether a connection can change things is fixed when you make it. To turn writing on or off, disconnect it and connect it again.
  • Signing in and keys are independent — revoking a key doesn't disconnect Claude, and disconnecting Claude doesn't revoke your keys. Both lists are on this page.
  • Every tool that changes something is marked as such, and Claude asks you before running one. That marking is what this site guarantees — whether you get asked is up to the assistant you connected.
  • Nothing here is specific to Claude: this is a standard Model Context Protocol endpoint and any agent that speaks it can connect.
