Connecting

Claude

Web, desktop and mobile. Nothing to copy but the address — you sign in instead.

  1. Open Add a custom connector in Claude. In the desktop or mobile app it's Settings → Connectors → Add custom connector.
  2. Paste this address:
  3. Claude sends you back here to sign in, and asks what you're allowing. Say yes.
  4. That's it — ask Claude about your auction.

ChatGPT

Needs a paid plan, and developer mode switched on. You sign in the same way.

  1. In ChatGPT's settings, turn on developer mode, then add an app for a remote MCP server. OpenAI move these menus around; their own guide has the current path.
  2. Paste this address:
  3. Choose OAuth when it asks how to authenticate. It sends you back here to sign in.
  4. Turn the app on from the + menu in a chat.

Grok

Web and apps. Nothing to copy but the address — you sign in instead.

  1. Open Connectors in Grok, choose New connector, then Custom. On a Grok Business or Enterprise account, an admin has to add it in the console first.
  2. Paste this address:
  3. Grok sends you back here to sign in, and asks what you're allowing. Say yes.
  4. Grok finds the tools on its own — ask it about your auction.

Keys, for everything that can't sign in

You don't need a key to connect Claude, ChatGPT or Grok — use the sign-in above. A key is for a script, a cron job, or a connector your organisation's administrator adds once for everybody. Anyone who has the key is you, so treat it like a password.

Using a key

Send it as a bearer token on every request:

curl -X POST {{ mcp_url }} \
  -H "Authorization: Bearer ak_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
