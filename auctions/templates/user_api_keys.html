Connect an AI agent to this site

An AI agent — Claude, ChatGPT, or anything else that speaks the Model Context Protocol — can use this site the same way you do: look up a lot, check who hasn't paid, add lots to your auction, check people in. It acts as you: every auction and club still checks your own permissions, so it can never do anything you couldn't do yourself.

What it can do

  • Ask it things: “how many lots are in my auction?”, “who hasn't paid yet?”, “when does lot submission close?”
  • Have it do things: add lots, check people in, record a sale, mark an invoice paid, add points.
  • Anything that would take a page with a form on it — creating an auction, deleting things, anything involving money changing hands — it will give you a link to instead of doing.
  • Pick a job off a menu. Claude offers four of them by name — work the door, chase unpaid invoices, set up next year's auction, write a club announcement — and each one walks through the whole thing rather than you having to describe it.
  • Ask for something it can't do, and it will write the request down for whoever builds these. Say what you were trying to do; that sentence is the part that gets read.

Keys, for everything that can't sign in

You don't need a key to connect Claude or ChatGPT — use the sign-in above. A key is for a script, a cron job, or a connector your organisation's administrator adds once for everybody. Anyone who has the key is you, so treat it like a password.

Using a key

Send it as a bearer token on every request:

curl -X POST {{ mcp_url }} \
  -H "Authorization: Bearer ak_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

Good to know

  • A connection can change at most 300 things an hour. That's far more than a busy check-in table needs, and it's the ceiling on how far something can go wrong before you notice.
  • Whether a connection can change things is fixed when you make it. To turn writing on or off, disconnect it and connect it again.
  • Signing in and keys are independent — revoking a key doesn't disconnect an agent, and disconnecting one doesn't revoke your keys. Both lists are on this page.
  • Every tool that changes something is marked as such, and a well-behaved agent asks you before running one. That marking is what this site guarantees — whether you get asked is up to the agent you connected.
  • What you can do changes what it can do. If you're given a new permission — made an admin of a club, say — reconnect or refresh the connection so it picks up the tools that come with it.
  • Nothing here is specific to one company: this is a standard Model Context Protocol endpoint and any agent that speaks it can connect.
