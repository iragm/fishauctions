{% comment %} Google's dynamic library import bootstrap loader for the Maps JavaScript API, verbatim from https://developers.google.com/maps/documentation/javascript/load-maps-js-api -- the loading method Google recommends. It defines google.maps.importLibrary and nothing else: the API itself is only fetched the first time a library is imported, which is why a page that never shows its map never downloads it. Google's page is explicit that the loader must only be included once per page. Include it only when a key is configured (`key` is the loader's one required parameter) and before any script that calls importLibrary. Expects google_maps_api_key. {% endcomment %}
