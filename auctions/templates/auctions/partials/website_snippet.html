{% comment %} One "put this on your website" block, rendered from a dict built by ClubWebsiteIntegrationView. Expects `snippet` with: title, icon, blurb, url, heights (a {count: pixel height} map), available, unavailable_reason, settings_url, and counts/max_count for the ones that take a ?count=. A snippet carrying `links` instead is the other kind: plain addresses rather than an iframe, for the things a club's own site already knows how to present (a "subscribe" button in their menu). It shares this card so the heading, the blurb and the switched-off note read the same either way. Everything is spelled out rather than generated by JavaScript, because the thing being handed over is text somebody copies into WordPress: a "copy" button that fails silently on an old browser leaves them with nothing, where a visible 
 always works.

Only ever use {% templatetag openblock %} comment {% templatetag closeblock %} blocks in here.
Django's {% templatetag openbrace %}# … #{% templatetag closebrace %} form is single-line only;
spread one over two lines and it renders straight onto the page.
{% endcomment %}
