Look up a species — GET https://{{ site_domain }}/api/v1/clubs/{{ club.slug }}/species-lookup/?q=yellow+lab
  • Matches typed text against this site's species list, the same way the add lot form does. Answers are always species that exist here.
  • No match is 200 with an empty results. A missing q is the one 400.
  • unambiguous is true only for exactly one match — that's the signal to act on. Up to {{ species_lookup_max_results }} results; total_matches is how many were found.
  • ?category=cichlids or ?category_id={% if example_category %}{{ example_category.pk }}{% else %}7{% endif %} (not both) re-orders candidates; it never filters. A category this site doesn't have is a 400.
  • Anything the database can't answer goes to a language model: {{ species_lookup_llm_calls_per_day }} a day for this club, shared by all its keys ({{ species_lookup_llm_remaining }} left today).{% if not species_lookup_llm_available %} No model is configured on this site right now.{% endif %} Every response carries X-Species-LLM-Limit, X-Species-LLM-Remaining and X-Species-LLM-Reset; a lookup that needed the model with none left is a 429.
curl "https://{{ site_domain }}/api/v1/clubs/{{ club.slug }}/species-lookup/?q=yellow+lab" \

  • full_scientific_name — the name to show a person. On a strain it includes the strain ("Neocaridina davidi 'Blue Dream'"); scientific_name is the plain species and is the same for every strain of it.
  • label — full scientific name plus common name, as the lot form shows it.
  • variety / parent — the strain, and the species it's a strain of. Both empty on an ordinary species.
  • category — the category a lot of this species gets here, or null.
  • trade_rank — 0 = kept in the hobby, 1 = its genus is, 2 = neither. Results are ordered by it.
  • approved — false means it is yours: visible to this club only, until a site admin approves it.
  • source — fishbase, aquarium (curated trade list), admin or manual.
  • source at the top level — how it was matched: exact, cache, search, llm or none.
Add a species — POST https://{{ site_domain }}/api/v1/clubs/{{ club.slug }}/species-lookup/
  • scientific_name is "Genus species" in one string, and is required unless you're adding a strain. A genus on its own is fine.
  • Optional: common_name, other_names (a list, or one comma-separated string), category or category_id, freshwater (default true), brackish, saltwater, breeder_points (default true).
  • A strain is variety plus parent, the id of the species it's a strain of. Neither works without the other.
  • What you add is visible to this club only, until a site admin approves it for everyone.
  • 409 if the species is already here, or if a name you sent already belongs to another species — the response carries that species, so use its id.
curl -X POST https://{{ site_domain }}/api/v1/clubs/{{ club.slug }}/species-lookup/ \
  -H "X-API-Key: {{ api_key.prefix }}.YOUR_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"scientific_name":"Ancistrus sp. L183","common_name":"Starlight bristlenose","other_names":["L183"]}'
A strain of a species that's already here:
curl -X POST https://{{ site_domain }}/api/v1/clubs/{{ club.slug }}/species-lookup/ \

Returns 201 and the species record, in the same shape the lookup returns.
Add a common name to an existing species — POST https://{{ site_domain }}/api/v1/clubs/{{ club.slug }}/species-lookup/<id or scientific name>/common-names/
  • Body: {"name":"yellow lab"}. The matcher finds the species by that name from then on.
  • Address the species by id, or by scientific name so you don't have to look the id up. A strain needs its full name, e.g. Neocaridina davidi 'Blue Dream'.
  • The name is visible to this club only, until a site admin approves it.
  • A name the species already has returns 200 with the existing one, so re-running an import is safe. A name that already belongs to a different species is a 409.
curl -X POST "https://{{ site_domain }}/api/v1/clubs/{{ club.slug }}/species-lookup/Labidochromis%20caeruleus/common-names/" \
  -H "X-API-Key: {{ api_key.prefix }}.YOUR_SECRET" \
  -H "Content-Type: application/json" \
