{% comment %} The shell every styled club embed uses: an admin pastes an iframe of one of these into WordPress, Wix or Squarespace and it has to look like it belongs there without knowing anything about the page it lands on. So the CSS lives here once, in four blocks — a light palette, a dark palette, a card, and a list — and each embed only supplies its rows. Three rules this file exists to enforce: * **Nothing but the rows.** No heading, no "More from" link, no club name. This is pasted into a page that already has its own heading and its own navigation, and a club that wanted a link back here would have written one; ours reads as somebody else's furniture in their room. * **One palette.** Four embeds that each carried their own copy of these variables drifted apart the first time one of them was touched, and a club that used two of them got two slightly different greys on the same page. * **No external requests.** No web fonts, no stylesheet, no script. This renders inside somebody else's site, often over a slow connection, and anything it fetches is another thing that can fail in public. `embed_mode` is "light" or "dark" and is picked by the ?format= the club chose, not by the visitor's system setting — the club knows what colour its own website is and we do not. Only ever use {% templatetag openblock %} comment {% templatetag closeblock %} blocks in here.
